# Catálogo V1

Esta pasta contém a nova fonte estruturada de dados comerciais.

## Atenção

Ela ainda não está conectada ao `src/app.js`. Não apague os arquivos antigos antes da etapa de integração e dos testes.

## Arquivos

- `config.json`: dados da loja, checkout e versão.
- `categories.json`: categorias de sabores.
- `flavors.json`: sabores e preços unitários.
- `boxes.json`: caixas montáveis e degustação.
- `products.json`: kits e produtos de preço fixo.
- `options.json`: adicionais.
- `combos.json`: estrutura reservada para combos.
