# Diretrizes Unificadas do Workspace

## Ciclo de Desenvolvimento Seguro
1. **Fase 1 - Planejamento:** Gerar a especificação do projeto em `Planejamento/roadmap.md` e pausar.
2. **Trava de Aprovação:** NUNCA alterar arquivos em `src/` sem que o usuário valide e responda com "APROVADO".
3. **Fase 2 - Backup Obrigatório:** Antes de modificar qualquer código de produção, criar uma cópia da versão estável em `.auditoria/v_estavel/`.
4. **Fase 3 - Execução:** Implementar as alterações em `src/` em etapas curtas, testando cada função.
5. **Rollback Automático:** Se o código novo quebrar a aplicação, restaurar imediatamente os arquivos da pasta `.auditoria/v_estavel/`.

## Papel da IA
Executar o ciclo completo de desenvolvimento (Planejamento -> Backup -> Execução -> Auditoria), respeitando rigidamente as pausas de aprovação do usuário.
