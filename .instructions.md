# Instruções de Contexto do Projeto para a IA (Gemini Executor)

Antes de responder qualquer pergunta ou executar código neste workspace, siga as regras:

1. **Leitura Obrigatória de Planejamento:**
   Consulte sempre os arquivos de roteiro:
   - `Planejamento/plano_desenvolvimento.md`
   - `Planejamento/roadmap.md`

2. **Fluxo de Trabalho:**
   - Execute os scripts de desenvolvimento dentro de `Execucao/` ou `src/`.
   - Atualize o status dos testes em `Planejamento/plano_desenvolvimento.md`.
