# Diretrizes de Desenvolvimento Autônomo por Módulos

## Regra de Execução
1. **Atuação por Módulo:** O desenvolvimento deve ser focado em 1 módulo funcional por vez (ex: Clientes, Estoque, Vendas, Financeiro).
2. **Execução Autônoma no Módulo:** Após a aprovação do plano do módulo, o Agente Executor deve criar o backup em `.auditoria/v_estavel/` e criar/alterar todos os arquivos do módulo sem fazer perguntas intermediárias.
3. **Pausa para Validação:** O agente só para ao concluir o módulo completo para que o usuário possa testar e fazer o commit seguro.
