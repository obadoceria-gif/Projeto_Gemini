# Plano de Finalização — Cardápio Oba Doceria

## Objetivo

Concluir a versão de produção do Cardápio Oba Doceria com o mínimo possível de trabalho manual.

## Fases restantes

1. Higienização automática e preservação segura
2. Gate final automatizado
3. Consolidação do repositório
4. Commit final
5. Sincronização com main
6. Publicação em nuvem
7. Smoke test público
8. Aprovação visual final
9. Liberação para clientes

## Critério de conclusão

O projeto será considerado finalizado quando:

- todos os gates automáticos estiverem verdes;
- não houver bloqueadores funcionais;
- a baseline estiver consolidada;
- o GitHub main estiver sincronizado;
- uma URL pública estiver funcionando;
- o smoke test de produção estiver aprovado.

## Regra de processo

Automatizar tudo que for tecnicamente possível.
Teste manual somente para aprovação visual final ou comportamento que exija julgamento humano.
