# Critérios de Aceite

## UI
- mesma identidade visual da versão moderna;
- navegação em etapas;
- modais funcionando;
- responsividade;
- sem regressão visual relevante.

## Catálogo
- caixas vindas do Modelo Mestre;
- sabores vindos do Modelo Mestre;
- categorias corretas;
- preços corretos;
- disponibilidade correta;
- imagens corretas.

## Regras
- capacidade de caixa respeitada;
- limite de sabores respeitado;
- totais corretos;
- opcionais corretos.

## Carrinho
- adicionar;
- remover;
- alterar quantidade;
- subtotal;
- total;
- persistência quando aplicável.

## Checkout
- nome;
- data;
- hora;
- pagamento;
- validações.

## WhatsApp
- telefone correto;
- mensagem correta;
- itens corretos;
- total correto.

## Qualidade
- Console sem erros;
- diagnósticos aprovados;
- Git limpo;
- documentação atualizada.
