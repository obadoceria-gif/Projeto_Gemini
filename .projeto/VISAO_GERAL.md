# Visão Geral do Projeto

**Projeto:** Cardápio Virtual Interativo — Oba Doceria  
**Versão do documento:** 1.0  
**Última atualização:** 06/08/2026  
**Status:** Linha de base inicial

## Objetivo

Construir uma vitrine digital mobile first para apresentação do catálogo da Oba Doceria, montagem de pedidos e envio de uma mensagem estruturada para o WhatsApp da loja.

## Proposta de valor

- navegação simples em celulares;
- catálogo visual e organizado;
- atualização de produtos, sabores, preços e disponibilidade por dados;
- carrinho com regras de negócio;
- atendimento direto pelo WhatsApp;
- baixo custo operacional;
- publicação estática em GitHub Pages ou Cloudflare Pages.

## Público-alvo

Clientes da Oba Doceria interessados em:

- doces e caixas para consumo ou presente;
- encomendas para festas, casamentos e eventos;
- produtos personalizados;
- consulta rápida de sabores, preços e disponibilidade.

## Escopo atual

O projeto em desenvolvimento contém uma estrutura inicial em HTML, CSS e JavaScript Vanilla, com tentativa de separação entre interface, configuração e catálogo. A versão atual ainda não está pronta para substituir o cardápio publicado.

## Visão de evolução

1. consolidar a governança e as regras;
2. criar um Modelo Mestre de Catálogo;
3. migrar os dados do repositório original;
4. estabilizar carrinho, caixas e WhatsApp;
5. validar UX e responsividade;
6. publicar a nova versão;
7. evoluir futuramente para um painel administrativo sem reconstruir o cardápio.

## Princípio central

> O código controla o comportamento; os arquivos de dados controlam o conteúdo comercial.
