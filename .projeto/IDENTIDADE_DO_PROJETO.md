# IDENTIDADE DO PROJETO

## Nome público
Cardápio Virtual Interativo — Oba Doceria

## Nome técnico do núcleo
Motor Comercial Oba

## Missão
Permitir que produtos, sabores, preços, caixas, kits, combos e disponibilidade sejam atualizados por dados centralizados, sem reescrever a interface.

## Visão
Manter um catálogo digital bonito, rápido, simples de usar e preparado para alimentar futuras interfaces, como painel administrativo, aplicativo e ferramentas internas.

## Princípios

- Mobile First.
- Arquitetura orientada por dados.
- Código simples e modular.
- Fonte única de verdade para dados comerciais.
- IDs estáveis e histórico preservado.
- Documentação viva.
- Git como histórico oficial.
- Independência de uma ferramenta específica de IA.
- Performance e clareza acima de efeitos desnecessários.
