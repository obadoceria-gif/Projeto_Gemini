# Publicar Alterações

## Fluxo

1. Faça a alteração pela Central.
2. Salve.
3. Confira o preview.
4. Verifique se há alteração pendente.
5. Clique em Publicar alterações.
6. Aguarde a propagação.
7. Confira a versão pública.

## URL pública

https://obadoceria-gif.github.io/Projeto_Gemini/ui-desenvolvimento/index.html

## Antes de publicar

Confira item, nome, descrição, preço, categoria e imagem.

## Depois de publicar

Confirme página pública, JSON e imagens.

## Segurança

Não editar diretamente a versão pública.
