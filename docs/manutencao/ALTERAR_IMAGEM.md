# Alterar Imagem

## Recomendado

Use a função de imagem da Central de Gestão.

Formatos utilizados pelo projeto incluem JPG/JPEG, PNG e WEBP.

## Validação

Depois da alteração confirme:

- preview;
- card do produto;
- imagem carregada;
- versão pública;
- HTTP 200.

## Caminhos do cardápio

Há compatibilidade com ui-desenvolvimento/Images/.
