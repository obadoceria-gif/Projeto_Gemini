# Manual do Cardápio Virtual Oba Doceria

## 1. Objetivo

O cardápio permite escolher caixas, selecionar sabores, revisar a montagem, adicionar ao carrinho, editar caixas existentes e seguir para a finalização.

## 2. Mínimo da caixa

O mínimo homologado é de 25 doces.

25 doces é o mínimo, não o máximo.

Ao atingir 25 doces, o sistema permite continuar escolhendo, revisar a seleção, adicionar ao carrinho ou finalizar.

## 3. Revisar / Editar seleção

Na revisão é possível aumentar, diminuir ou remover sabores e escolher outros sabores.

Abaixo de 25 doces, Salvar alterações permanece desabilitado.

## 4. Salvar montagem

Ao salvar uma montagem válida, a caixa é registrada e o carrinho é aberto.

A caixa não deve ser duplicada.

## 5. Editar caixa

No carrinho use Editar caixa.

A edição modifica o item existente.

Exemplo homologado:

- 25 Cappuccino: R$ 62,50
- 26 Cappuccino: R$ 65,00

## 6. Continuar comprando

O carrinho permanece preservado.

Depois de concluir a edição, EDITANDO CAIXA deve desaparecer.
